Install on Linux

  1. Open the Snap Store page above and select Install, or run the command below in a terminal.
  2. Open Spark Chamber from your apps.
  3. New beta versions install automatically.
sudo snap install spark-chamber --beta

Ubuntu includes snap. Other Linux distributions need snapd installed first.

Before you start

  • This is Early Access. Expect rough edges and missing regions.
  • Updates keep your progress. Copy a backup from Settings now and then anyway.
  • Found a wrong answer or a bug? Use Report a problem in the app.
  • Hands-on builds use battery or USB power only, 12 V or less. Read the safety notes first.

Release notes

0.2.02026-10-02
  • The basics verified problem by problem: the eight center topics (134 problems) were re-derived independently.
  • The Bench, in the Workshop: place and wire parts, predict a reading, then probe it with a multimeter. Drag a part's value and the meter follows.
  • A worksheet calculator (Ctrl+K) with units, complex numbers and E-series rounding.
  • The Ohm's law wheel, and a Terms page with 64 terms and short drills.
  • Lighting a topic now takes five in a row, each one harder than the last.
  • Simulator: adaptive time steps and a guided flyback lab.

Known limits: the Bench has a multimeter only for now.
